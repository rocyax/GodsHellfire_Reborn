These are source codes for **GodsHellfire_Reborn** mod

An unofficial continuation of the discontinued God's Hellfire mod originally created by L0st_Illusi0n.

This is a cheat/debug mod that adds three admin items. You can find them in Cheat Sheet or Hero's Mod.

The mod utilizes AIGC (GPT-5.6 sol & Opus5) but has undergone rigorous testing.

The mod might be incompatible with multiplayer mode.
